# 条件建议复盘

1. 使用案例冻结的原始证据、投资期限、建议版本和条件。评价窗未满或行情口径不一致时保持待评估。
2. 优先核对进入条件是否全部满足，退出或失效条件是否任一满足。事件、基本面与复合条件没有证据就标为无法核验，不能自行假设满足。
3. 区分未触发、无法核验、等待下一交易日、触发后的假设结果。未触发不判交易亏损，也不能凭后续上涨判错过机会。
4. 价格条件仅在明确的相同不复权口径下计算；收盘触发假设次日开盘进入，不做当日回转。成交、涨跌停、分红、流动性和账户实际收益不在该代理评估内。
5. 信号时点已明确存在而未处理的缺口才能归为 ex_ante_miss。逐条指向冻结快照的证据，不引用事后新信息或模型常识补全。
6. 生成的经验保持 candidate，记录原案例、行业、投资期限和单样本局限；未经批准不注入交易判断。
7. 对照评测只读取冻结的信号时点事实。结果标签不能进入模型输入；同配置比较有记忆和无记忆，报告真实用量及样本不足，不自动调整策略。

本说明用于内部反思角色，不新增工作台账户工具。权限、时点、预算及条件计算以 Python 契约为准。
